# Sentinel S3 Cloud Honeypot

> A free, educational cloud-based honeypot built on AWS S3 — designed to detect, log, and analyze unauthorized access attempts.

---

## About the Project

**Sentinel S3 Cloud Honeypot** is a cloud security tool that simulates a vulnerable AWS S3 environment to attract and monitor malicious actors. It was built as a capstone project for the **Cloud Computing** program at **Miami Dade College**.

This project demonstrates real-world threat detection techniques using cloud-native services — entirely free and open for educational use.

## Features

- Cloud-hosted honeypot using AWS S3
- Logs and monitors unauthorized access attempts
- Educational tool for understanding cloud threat vectors
- Free to deploy and use

---

## Tech Stack

- **Cloud Provider:** AWS (Amazon Web Services)
- **Storage:** Amazon S3
- **Purpose:** Threat detection & cloud security education

---

## Educational Use

This project was created for educational purposes as part of a Cloud Computing capstone course. It is intended to help students and security enthusiasts understand:

- How attackers target misconfigured cloud storage
- How to set up honeypots in a cloud environment
- Basic cloud security monitoring principles
